# Weather Service

Сервис для получения прогноза погоды через [Яндекс.Погода API](https://yandex.ru/dev/weather/).

---

## Перед запуском
Создать файл `src/main/resources/application.properties` c переменными:
```properties
api.weather.url=https://api.weather.yandex.ru/v2/forecast
api.weather.key=
```
